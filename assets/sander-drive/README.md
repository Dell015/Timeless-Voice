# Sir Sander's Google Drive: folder template

These folders are the template for the shared Google Drive Sir Sander uploads to.
Upload this whole folder to Google Drive, share it with Sir Sander, and he fills each folder.

- Each folder has a `_READ-ME.txt` that tells him what to upload.
- Some folders also have a `_SCRIPT.txt` with lines to record.
- The files are plain text so they open easily on a phone.
- Nothing here is part of the website. It lives in `assets/` only for safekeeping.
- This README is for you. You do not need to upload it to the Drive.
