# Timeless Voices: Questions Log

Every question we raise goes here, so nothing gets forgotten.

## How this file works

1. Every new question gets an ID and is added under **Open**.
2. When a question is answered, it moves to **Answered**, with the answer and date.
3. **Every time a question is answered, update BOTH files:**
   - this file (move it to Answered)
   - `timeless-voices-brain.md` (add the decision under Confirmed, remove it from Open Questions, and add any feature it created)
4. If an answer creates new questions, add them here immediately.
5. Features and ideas that come out of answers must land in the brain file so they are not lost.
